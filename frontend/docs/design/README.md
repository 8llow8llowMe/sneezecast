# 디자인 소스 읽는 법

이 폴더는 Claude Design 캔버스 "우리동네체온계 홈 시안"에서 내보낸 원본입니다.

## 파일 구성

- `screens/*.dc.html` — 화면 하나가 파일 하나입니다. 모바일은 접미사 없음, 태블릿은 `-T`, 데스크톱은 `-D`입니다.
- `canvas.json` — 캔버스 배치와 각 화면의 제목(`boards.*.title`)입니다. 화면 이름은 여기서 확인합니다.
- `tokens.json` — 색, 글자 크기, 모서리, 간격, 상태 규칙입니다. 코드의 디자인 토큰은 이 파일을 기준으로 만듭니다.
- `SCREENS.md` — 화면 ID, 파일, 제안 라우트 대응표입니다.

## `.dc.html` 해석 규칙

- `<x-dc>` 안의 마크업이 화면입니다. 스타일은 모두 인라인이라 값(px, 색)을 그대로 읽으면 됩니다.
- `{{word}}`, `{{meta}}` 같은 이중 중괄호는 데이터 자리입니다. 실제 값은 같은 파일 아래 `<script type="text/x-dc">`의 `renderVals()`에 상태별로 들어 있습니다.
- `<sc-if value="{{hasData}}">`는 조건부 영역, `<sc-for list="{{bars1}}">`는 반복 영역입니다.
- `<dc-import name="Home" level="자료 부족">`은 다른 화면(Home.dc.html)을 그 상태로 끼워 넣은 것입니다. 시트·대화상자 화면의 배경으로 쓰였습니다.
- 서체 경로 `/_blob/...`은 캔버스 전용이라 로컬에서는 열리지 않습니다. 구현에서는 npm `pretendard` 패키지를 씁니다.
- 동 이름, 참여자 수, 비율, 날짜는 모두 예시 값입니다. 실제 값은 API에서 받습니다.
- `Flow.dc.html`은 시연용 프로토타입이라 상태 전환 로직(보고 → 공개 기준 도달 → 변화 공개)을 참고용으로 담고 있습니다.

## 우선순위

화면 명세서(`docs/screen-spec.md`) > 이 폴더의 시안 > `tokens.json` 순서로 따릅니다. 서로 다르면 명세서가 맞습니다.
